# Sales Performance Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive Sales Performance Dashboard built using Microsoft Power BI. It helps analyze sales quantity, payment methods, state-wise performance, order dates, and profitability.

## Dashboard Features
- KPI cards for key business metrics
- State-wise sales and quantity analysis
- Sales quantity by product or category
- Payment mode distribution
- Monthly profit analysis
- Sub-category-wise profit comparison
- Interactive filters for order date and state

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- Data Visualization
- DAX (if used in the project)
